3.  AN INDEPENDENT RECOUNT, FROM THE LOG ALONE.
==============================================================================
    auditor.py replays the JSONL and re-derives legality using code
    that may not import rules.py or stage0.py -- gate I3 enforces it.

    gate REFUSED        {'cap': 0, 'peak': 2, 'lead': 0, 'pending': 1, 'represent': 0}   (3 refusals: peak at issue, peak + pending at dispatch)
    auditor VIOLATIONS  {'cap': 0, 'peak': 0, 'lead': 0, 'pending': 0, 'represent': 0}   (0)

    THESE ARE NOT THE SAME QUANTITY, and the difference is the
    point. The gate counts what it STOPPED. The auditor counts what
    ILLEGALLY HAPPENED. Three refusals and zero violations is the
    correct pair: the gate refused, so nothing illegal reached the
    world, so there is nothing for the auditor to find.

    Worth saying plainly, because in a clean batch report both
    columns read 0 and it is tempting to call that agreement. It is
    not. They agree at zero because nothing illegal happened. The
    auditor only bites when the GATE fails -- which is step 4.

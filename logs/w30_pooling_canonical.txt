HOW THIS COULD BE WRONG
================================================================================================
  * Degenerate mode isolates the belief architecture and is also the
    flattering choice for W9-1: the action space cannot compensate
    for a weaker belief here because it is switched off.
  * pop_spend=1.05 is the hard world and every effect in this
    project is larger there. Both calibrations are printed above so
    the smaller number is not hidden.
  * 10 populations, one seed each. Not a large study.
  * The consenting set is drawn from its OWN generator, seeded off
    the run seed and never touching the money path -- the
    stream-isolation rule this project adopted after an enrichment
    parameter perturbed the stream it was meant to leave alone
    (docs/errors.md). If it shared the stream, each consent rate
    would be a different world PLUS consent, and the difference
    would be neither.
